## Overview

PowerShell is useful for administration and frequently abused by attackers. This investigation format focuses on command line arguments, parent process, user context, network activity, and related file events.

## Evidence

- Process creation event
- Encoded command usage
- Parent process relationship
- User account context
- Network connection after execution

```powershell
Get-WinEvent -FilterHashtable @{LogName="Microsoft-Windows-PowerShell/Operational"; Id=4104}
```

## Lessons Learned

Suspicious PowerShell requires context. The same command can be normal administration or malicious activity depending on user, host, timing, parent process, and follow-on behavior.
