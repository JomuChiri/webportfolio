## Overview

The Active Directory lab supports hands-on practice with domain users, authentication flows, account access troubleshooting, Windows logging, and security monitoring.

## Objectives

- Create domain users and groups.
- Practice password resets and access troubleshooting.
- Understand logon events and authentication evidence.
- Connect endpoint logs to SIEM workflows.

## Detection Opportunities

- Failed logon bursts
- New local administrator membership
- Suspicious PowerShell execution
- Account lockout patterns
