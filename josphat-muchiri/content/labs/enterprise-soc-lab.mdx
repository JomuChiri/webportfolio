## Overview

The Enterprise SOC Lab is a structured environment for learning security operations by building and documenting real systems. It supports endpoint logging, network segmentation, vulnerability scanning, SIEM ingestion, alert review, and investigation practice.

## Objectives

- Build realistic Windows and Linux telemetry.
- Practice alert triage and event correlation.
- Document configuration steps and lessons learned.
- Map detections to MITRE ATT&CK where appropriate.
- Create reusable investigation notes.

## Tools

| Tool | Purpose |
| --- | --- |
| Wazuh | Endpoint security monitoring |
| Splunk | Search, dashboards, and log analysis |
| Sysmon | Windows endpoint telemetry |
| OpenVAS | Vulnerability scanning |
| pfSense | Firewall and network segmentation |
| Kali | Attack simulation and testing |

## Challenges

- Keeping logs structured and searchable
- Avoiding noisy detections
- Documenting enough detail for repeatability
- Mapping technical signals to analyst decisions

## Lessons Learned

The most valuable lab output is not only that the tools run. The value comes from repeatable documentation, evidence capture, clear detection logic, and lessons that can be explained during interviews.
