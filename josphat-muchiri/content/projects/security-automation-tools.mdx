## Overview

This collection exists to turn repeatable support and security tasks into small, documented utilities. Each script should have a clear input, predictable output, error handling, and a short usage guide.

## Operating Principles

- Keep scripts readable.
- Validate inputs before execution.
- Log actions that matter.
- Document assumptions.
- Prefer practical value over complexity.

```bash
./collect-host-context.sh --host workstation-07 --format json
```

## Portfolio Value

Small automation projects show how Josphat approaches problem solving: identify a repeated task, reduce manual work, document the result, and keep the tool maintainable.
