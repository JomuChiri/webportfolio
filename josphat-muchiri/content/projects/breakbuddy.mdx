## Overview

BreakBuddy is a desktop wellness assistant concept for people who spend long hours in technical focus work. It supports work timers, break reminders, idle detection, activity prompts, and a simple activity library.

## Target Users

- Developers
- SOC analysts
- Gamers
- Students

The project connects software development with realistic user needs: reducing fatigue, improving consistency, and giving technical workers lightweight support without intrusive design.
