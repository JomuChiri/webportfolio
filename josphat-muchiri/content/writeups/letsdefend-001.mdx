## Overview

This write-up format keeps the focus on analyst reasoning. Each case should show the alert, evidence, analysis, decision, and lessons learned.

## Structure

- Alert summary
- Source and destination context
- Evidence
- Analysis
- MITRE mapping
- Final decision
- Lessons learned
