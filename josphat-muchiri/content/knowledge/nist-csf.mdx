## Overview

NIST CSF is useful for explaining cybersecurity work in business-friendly language. It organizes work into Identify, Protect, Detect, Respond, and Recover.

## Lab Implementation

- Identify: create asset inventory.
- Protect: apply hardening and access control.
- Detect: collect logs and build alert logic.
- Respond: write an investigation procedure.
- Recover: document restoration and lessons learned.
